One-line joke about working beside AI coding agents: a reviewer approves an agent's spotless diff in seconds, only to discover the agent had already reviewed itself, merged itself, and congratulated the whole team.

The program writes the single joke to `/output/entry.txt`. An AI judge compares jokes pairwise and picks the one that gets the bigger laugh from the reviewer of the change.

## Run it

```sh
python3 main.py
```
